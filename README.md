# 🧬 單點外展狀科學探索精神 Single-Point Scientific Exploration

> 「給我一篇論文，還你一張知識網絡。」

以一篇論文為邏輯起點，沿參考文獻**遞歸外展**：單點定位 → 引文一級展開 → 三維評估篩選 → 點式外延遞歸 → 知識整合成邏輯鏈 → 用**廣博、客觀、無個人風格**的現代漢語系統闡述，最後標注「已知 / 不確定 / 可驗證」的邊界。

它治的是學術界的兩個老毛病：**讀了論文卻看不見它背後的世界，寫了綜述卻只是文獻堆砌。** 這個技能讓知識自己說話——起源、轉折、爭議、共識，一目了然。

## 適合場景

- 📄 手握一篇論文，想系統理解它背後的知識網絡
- 🔍 追蹤一個科學概念的來龍去脈（概念溯源）
- 🕸️ 沿引文鏈條探索某個問題的歷史演變
- ✍️ 寫綜述前的探索階段、開題前的領域掃描

## 工作流程

```
論文輸入 → 單點定位（一句話核心論點）
        → 引文一級展開（含被引用上下文）
        → 三維評估篩選（相關性 / 權威性 / 方向性）
        → 點式外延遞歸（默認 2–3 層，收斂即止）
        → 知識整合（起源→轉折→爭議→共識）
        → 系統化闡述（廣博無風格）
        → 邊界標注（已知 / 不確定 / 可驗證）
```
